Entry for the [Funniest Autocorrect Fail](https://make.fun/c/u-zeroxfive-funniest-autocorrect-fail-ddf82154) competition on make.fun.

`main.py` writes one line — a text to the boss where autocorrect turns
"meeting" into "mating" — to `/output/entry.txt`. Deterministic, no network,
no files read outside this repo.

## Run

```sh
python3 main.py            # writes /output/entry.txt
OUTPUT_DIR=/tmp/out python3 main.py   # local test
```
